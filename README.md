## 本地启动与模型配置

完整启动、测试、IDEA 和剩余问题说明见 `docs/11-剩余任务与问题总结.md`。所有命令从 `D:\毕业设计\RAG软件工程知识问答系统` 执行，各服务使用独立 PowerShell 终端：

```powershell
.\scripts\Start-Local.ps1 -Service mysql
.\scripts\Start-Local.ps1 -Service rag
.\scripts\Start-Local.ps1 -Service backend
.\scripts\Start-Local.ps1 -Service frontend
```

如果端口已占用且服务健康，不要重复启动。前端地址 `http://127.0.0.1:5173`，后端 8080，FastAPI 8000，项目数据库 3307。管理员账号为 `admin`；密码仅在本机受保护的 `.runtime/local.properties` 的 `LOCAL_ADMIN_PASSWORD` 中查看，不复制到文档或源码。

当前模型服务为 `https://api.deepseek.com`，API 模型标识为 `deepseek-flash`。只有需要更换本地模型配置时才执行以下脚本，并按提示输入隐藏 API Key，再重启 FastAPI、刷新页面（现有配置不必重建）：

```powershell
.\scripts\Configure-ChatModel.ps1
```

API Key 使用 Windows 当前用户加密后存入 D 盘 `.runtime/model.config.xml`，启动时仅解密到进程环境，不发送给前端；该文件不可当作跨机器通用配置。生成回答只发送本轮问题（明确追问会结合上一问题补全指代）及检索片段，原始历史不发送；通用补充仅发送原问题。DeepSeek 使用非思考模式，依据生成启用 JSON 输出；适配依据为官方 `api-docs.deepseek.com/updates/` 和 `api-docs.deepseek.com/api/create-chat-completion/`，核对日期 2026-09-24。

IDEA 打开整个项目目录、加载 `backend/pom.xml` 后，选择 `RagQa Local (D drive)` 启动 Spring Boot。它只启动后端，MySQL/FastAPI/Vue 仍分别运行。若当前 8080 后端已运行，应先停止该后端再从 IDEA 启动，不能重复占用端口。启动细节见文档 11。

## 项目原则

1. 回答必须可追溯到知识库证据；证据不足时明确拒答。
2. 密钥、密码和连接凭据不得写入源码或提交版本库。
3. 性能、正确率和召回率只记录实测结果，不把目标值当成结果。
4. 原始资料必须记录来源和授权状态，扫描件 OCR 不作为首期核心能力。
5. 正式实验资料和外部模型服务需确认授权与学校要求；当前本地开发联调不替代正式验收。
